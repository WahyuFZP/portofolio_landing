## Scope

Ticket Space is a ticketing platform built with Next.js, TypeScript, Tailwind CSS, and PostgreSQL. This project focuses on its quality: finding defects before users do.

## Approach

- Wrote detailed test cases covering the platform's main user flows.
- Executed the test scenarios, including automated checks with Selenium.
- Documented every defect as a bug report and tracked it on a Jira Kanban board until resolved.
