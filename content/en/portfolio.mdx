## Problem

The first version looked fine but had real defects: project detail pages did not work, English pages showed Indonesian text, and a preloader delayed content on every visit. Mobile Lighthouse Performance was 56.

## Approach

Before redesigning anything, I wrote an end-to-end suite against the old site. Known bugs were recorded as expected failures, so each fix turns a test from red-expected to green.

- Playwright tests on desktop and an emulated Pixel 7.
- axe-core accessibility scan as part of the suite.
- A GitHub Actions workflow is set up to run lint, type checking, build, and E2E on every push.

## Result

The redesign keeps the same suite as a regression safety net. Each known bug is now a passing test.
